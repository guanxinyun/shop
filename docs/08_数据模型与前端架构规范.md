# 《工坊物语》数据模型与前端架构规范

---

## 一、 系统架构职责划分（分工铁律）

为保证经营游戏“账目绝对严密、游戏性公平、AI不胡言乱语”，系统采用**双层混合架构**：

```
                    ┌─────────────────────────┐
                    │    玩家操作界面 (Web)   │
                    │ 翻书 / 选用手法 / 开价  │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │ 前端确定性引擎 (JS Core)│
                    │ · 账本货币进位运算      │
                    │ · 债务到期时钟推进      │
                    │ · 耐心值扣除与背包格子  │
                    │ · 物理掷骰 (1d20+加值)  │
                    │ · 药性七维直接相加      │
                    │ · 抽取初始澄澈度 (3~7)  │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │   LLM 唯象叙事中枢      │
                    │ (DeepSeek/Claude/GPT)   │
                    │ · 读取底层判定与真实数据│
                    │ · 渲染客观感官事实描写  │
                    │ · 呈现顾客动态多元反应  │
                    └─────────────────────────┘
```

1. **确定性核心（Deterministic Core / JavaScript）**：
   - 承担所有加减乘除、金钱兑换（1 金币 = 100 银币 = 10000 铜币）、背包槽位；
   - 负责真正的伪随机数骰子（投 1d20、抽 3~7 初始澄澈度）；
   - 负责配方区间的数学判定（合格/不合格）；
   - **严禁让 LLM 碰账本加减法，避免算错账崩盘**。
2. **叙事渲染层（Semantic Layer / LLM API）**：
   - 只接收前端传入的已裁定数据（如：动作 = 骨锤轻敲，结果 = 发现冷隔暗纹，顾客态度 = 随性急着去喝酒）；
   - 负责把这些数据组织成带有日式轻西幻生活流质感、细腻清爽的感官描写与对白。
