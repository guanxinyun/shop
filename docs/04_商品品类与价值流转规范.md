# 《工坊物语》商品品类与价值流转规范

---

## 一、 八大物产门类与对应工匠熟练度

商品划分为 **8 大经典日式西幻门类**。玩家在柜台的每一次鉴定、拆解与出货，都会积累对应门类的专精熟练度（Lv.0 见习 $\rightarrow$ Lv.5 街区名匠）：

```
                    ┌─────────────────────────┐
                    │      小镇杂货铺物资全景 │
                    └────────────┬────────────┘
        ┌────────────────┬───────┴────────┬────────────────┐
        ▼                ▼                ▼                ▼
  【草药与生息】   【矿石与结晶】   【兽骨与毛羽】   【药剂与蒸馏液】
  · 对应：草木辨析 · 对应：脉理鉴识 · 对应：生息解构 · 对应：调和工艺
        │                │                │                │
        ├────────────────┼────────────────┼────────────────┤
        ▼                ▼                ▼                ▼
  【器物与法具】   【纸帛与卷册】   【日用生计器】   【怪奇与旧物】
  · 对应：器脉构筑 · 对应：文脉勘验 · 对应：百工物候 · 对应：闻识阅历
```

1. **草药与生息植株**（Herbs）：银叶草、蓝苔、露水菌。极度受物候与湿度影响，调和基础溶剂。
2. **矿石与结晶**（Minerals）：魔晶原石、铁片、含硫黄铜。性质稳定，器具骨架与稳固剂。
3. **兽骨、角甲与毛羽**（Fauna）：硬角、蛛丝、火蜥蜴皮。单极浓缩素材，烈性猛料，易引起冲撞。
4. **药剂与精油**（Potions）：工坊自制成品或回收残次试剂，面向镇民与公会，利润主力。
5. **器物与轻法具**（Artifacts）：单晶法杖、导魔手镯、指针。单价高，需特定对口客商。
6. **纸帛、封印与古卷**（Parchments）：法师草稿、地契旧纸、拓本。用于配方解锁与委托。
7. **日用生计百工器**（Civilian Wares）：铸铁锅、防风风灯、砝码。周转最快，民生刚需。
8. **怪奇与沉淀旧物**（Curios）：古代残片、海螺化石、旧徽章。信息差极大，高风险高收益。

## 二、 三轨价值模型（Three-Track Value Model）：杜绝数值通胀

为保证世界观扎实、物价符合平民小镇常理，**高级特性绝不等于直接无脑翻百倍价格**：

```
                  ┌──────────────────────────────┐
                  │       物品真实价值三轨模型   │
                  └──────────────┬───────────────┘
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
   【市井通货轨】          【工坊加工轨】          【特定委托溢价轨】
   (面向普通顾客/出货箱)   (自己入药/工坊自用)     (面向布告栏/学者悬赏)
   · 价格克制，按日用基准  · 高阶Tag转化为核心安全垫· 溢价幅度高 (+150%~300%)
   · 涨跌幅在 2~4 倍区间   · 抹平冲撞/药水品质跃迁 · 需匹配特定NPC需求
```

1. **市井通货轨（平民消费上限）**：
   - 普通生铁矿 10 铜币；带 Lv.3 均匀晶粒 25 铜币；哪怕带 Lv.5 罕见纹理，在通货市场封顶 40~60 铜币（4~6倍区间）。
   - 普通平民不会为用不上的高阶属性买单。
2. **工坊自用轨（生产资本质变）**：
   - 高阶特异原材如果留给自家坩埚，可作为**催化稳定垫**，抹平暴沸风险，产出价值几十银币的无瑕级成药。
3. **特定委托溢价轨（精准兑现）**：
   - 匹配公会高悬赏或特定学者订单，指名收购特定Tag，换取高额赏金与专属声望。

## 三、 特殊等级物品（Tier 5~6 / 罕见特质）的去向与上层客群

绝不让高阶物品沦为货架死库存，提供两条极具满足感的变现渠道，并深度联动小镇的上层消费阶层：

*   **去向 A：小镇布告栏定向高额收购 与 上层贵宾私密订制（Bounty & Commission）**：
    *   **学者工坊/公会悬赏**：指名要“内部双折射”水晶研磨镜片；
    *   **名门大管家的私密订单**：领主府邸管家指名要“澄澈度 $\ge 8$ 且带有【完全不苦】”的高阶舒缓露，全额支付 200% 以上溢价，并附带品鉴津贴；
    *   **土豪矿主的排场消费**：只要外观璀璨、经工坊抛光翻新且带有古代铭文的器物，土豪愿意以高倍价格买下用于宴会炫耀；
    *   **贵族少爷/千金的奇趣搜求**：为罕见特异词缀（如【夜间微光】、【风音共鸣】）一掷千金。
*   **去向 B：后院炼金坩埚的“奇迹催化剂”（Catalyst）**：
    *   充当绝对稳定垫，锁定最高澄澈度；
    *   激发专属特异效果（如【完全无味】、【持效翻倍】）；
    *   令成药直接跃迁为高阶名品。

## 四、 专属陈列设施：【礼宾玻璃陈列柜】（Showcase）

为配合上层客群的消费习惯，店铺前厅设立专属展示机制：
*   **功能定位**：普通杂货走木板架或出货箱，而无瑕级药水（澄澈度 $\ge 8$）或精心翻新、带有正面特异Tag的高阶器物，可陈列于正前方的【礼宾玻璃柜】中；
*   **客群引流效应**：陈列柜中的高阶展品直接决定店铺的**格调声望**。展品品质越高，吸引名门大管家、富商土豪与贵族千金进店触发高额收购的概率就越高！
