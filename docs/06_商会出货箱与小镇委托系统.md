# 《工坊物语》商会出货箱与小镇委托系统规范

---

## 一、 商会统购出货箱（The Guild Shipping Bin）：每日稳健托底

在铺子后门处立有一只包着黄铜防盗边角的大木箱——**【商会每日集运箱】**（机制借鉴《星露谷物语》出货箱）。

```
┌─────────────────────────────────────────────────────────────┐
│ 📦 柜台面对面零售 vs 商会统购出货箱                         │
├─────────────────┬───────────────────────────────────────────┤
│ 销售渠道        │ 运转机制与收益特点                        │
├─────────────────┼───────────────────────────────────────────┤
│ 1. 柜台零售     │ · 面对进店散客，每天客流有限（3~5人）。   │
│    (Front Desk) │ · 消耗掌柜耐心值，通过推销与找茬博弈。    │
│                 │ · 收益最高：可获得 120% ~ 150% 零售溢价。 │
├─────────────────┼───────────────────────────────────────────┤
│ 2. 商会统购箱   │ · 随时将多余药水、量产货、杂物扔进木箱。  │
│    (Shipping)   │ · 零门槛、无限量、不挑剔，商会全额兜底。  │
│                 │ · 价格稳定：按【基准市场价 100%】全额结算。│
│                 │ · 每日清晨/傍晚结算，马车拉走货物，现钱到账│
└─────────────────┴───────────────────────────────────────────┘
```

### 核心定位：
*   **彻底告别压货滞销**：练手做出的多余标准药剂、鉴定完毕的多余原材，随做随卖，每天傍晚变成银币，现金流永远不卡死。
*   **出货分流**：普通货扔箱子保底，极品/特异药水留着交高价委托。

## 二、 星露谷式小镇布告栏委托（Town Notice Board）

店外悬挂的软木布告栏上，每天清晨钉着镇民们的委托便条。

### 1. 核心机制规则
*   **严格的时限：2 ~ 5 天**（有时效张力，但不逼死人，足够玩家向商会加急订料并开炉制作）。
*   **超额溢价报酬**：通常为基准市价的 **150% ~ 300%**。
*   **小镇好感度系统（Friendship 0~5 心）**：
    *   每完成一次委托增加对应居民的好感点数。
    *   好感提升解锁专属日常回馈（面包房大娘送热苹果派、铁匠大叔送精钢边料并优惠改造工具、游侠赠送秘境草药地图）。

### 2. 经典委托案例库

#### 📌 案例 A：【面包房玛尔塔大娘的急件】（时限：2 天 · 急件）
*   **便签内容**：*“后天就是麦香节了，我得通宵揉面烤面包！腰酸背痛得直不起来。急求两罐【柔顺温热骨膏】，千万别加刺鼻生姜味，不然我的面团全毁了！”*
*   **要求**：数量 2 罐，`热性 ≥ 3`，`柔顺 ≥ 2`，澄澈度 $\ge 5$，排除 `【刺鼻辛辣】`。
*   **报酬**：**24 银币**（200% 溢价）+ 热核桃派 $\times 1$（可食用回复精力）+ 玛尔塔好感 $+1$ 心。

#### 📌 案例 B：【铁匠汉斯的烫伤药膏】（时限：2 天 · 急件）
*   **便签内容**：*“生铁火星子崩进围裙，烫起大水泡，订单赶着交差没法停工！急求一罐清凉镇痛软膏，抹上去立刻止痛的！”*
*   **要求**：`冰性 [3~5]`，`澄澈度 ≥ 4`。
*   **报酬**：**14 银币** + 一小包优质精钢边角料（可用于工坊升级工具）。

#### 📌 案例 C：【见习骑士雷欧的初次远征】（时限：4 天 · 批量大单）
*   **便签内容**：*“下周巡逻队进入迷雾深处，订购 3 瓶标准的【解毒净水滴剂】。薪饷虽少，但我拿奖章抵押了，报酬绝不少给！”*
*   **要求**：3 瓶批量成药，`冰性 [2~4]`，`纯净度 ≥ 5`。
*   **报酬**：**36 银币**（全款大单，还债的救命钱）。
