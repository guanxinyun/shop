# 《工坊物语》柜台鉴定与记事簿博弈系统规范

---

## 一、 核心闭环流程

```
┌─────────────────────────────────────────────────────────────┐
│ 顾客携带物品进店：展示初始耐心值（通常 3 ~ 5 点）          │
├─────────────────────────────────────────────────────────────┤
│ 1. 基础视野与回声共鸣（完全免费）：                         │
│    · 掌柜等级达标的标签已自动揭示（经验本能）。             │
│    · 视野中展示物品的基础外观与可感知的异常表征。           │
│    · 柜台上的【回声宝珠】自动共鸣，显示未探明特质总数       │
│      （纯数量，绝对不显示正面/负面，不消耗任何耐心）。      │
│                                                             │
│ 2. 翻阅《工坊备忘记事簿》（消耗 1 点耐心）：                │
│    · 基于异常表征，检索出 2~3 条极为相似的手札历史记录。    │
│    · 包含正解与“带微妙关键修饰词偏差”的干扰陷阱项。        │
│                                                             │
│ 3. 动手执行鉴定（消耗 1 点耐心）：                          │
│    · 从 10 种标准工坊检验手法中选择一种进行实操。           │
│    · 正确：揭示新标签并给出客观物理反馈。                   │
│    · 错误：白费功夫，甚至可能损坏物品、导致扣除更多耐心。   │
│                                                             │
│ 4. 柜台议价出价（消耗 1 点耐心）：                          │
│    · 基于当前已探明信息开价。落子无悔，进入成交判定。       │
└─────────────────────────────────────────────────────────────┘
```

## 二、 顾客耐心值（Action Budget）：统一行动力资源

进店的客人有各自的生活节奏：有人赶着去酒馆喝麦酒，有人想抓紧换钱去铁匠铺，也有人只是顺路进店闲聊。

1. **统一行动池**：
   - 每位顾客有 **3 ~ 5 点耐心**（以界面小圆点或沙漏显示：`[● ● ● ○]`）。
   - **基础感知与回声宝珠完全免费**（这是掌柜本能与固定仪器）。
   - **只有深入动作消耗耐心**：
     - **翻书查找线索（-1 耐心）**；
     - **拿起工具动手实操检验（-1 耐心）**；
     - **正式开口议价出价（-1 耐心）**。
2. **落子无悔与吹单规则**：
   - 一旦在输入框填入金额并点击【出价】，交易立刻拍板进入顾客心理底线判定，**后续绝不可追加鉴定**。
   - 若在鉴定与翻书上耗尽了所有耐心值，且剩余出价次数不足以达成共识，顾客会失去耐性，抓起货物直接离去。

## 三、 基础感知仪器：【回声宝珠】（Echo Orb）

为保证操作空间并杜绝信息泄露，探测仪器遵循**“免费感知、纯数字无极性”**准则：

*   **道具形态**：柜台天平旁常驻的一枚带有微细划痕的黄铜底座紫晶球。
*   **功能机制**：
    *   **完全免费，不消耗任何耐心点数**。物品放在柜台上时，宝珠与物品内部魔力/物性杂质自然引起微弱共鸣。
    *   **仅展示未探明特质总数，绝对不显示正面/负面（无金色/灰色之分，无好坏倾向）**！
*   **系统反馈范例**：
    *   “宝珠泛起微光，内部回荡起 3 声短促轻响。（检测到未探明特质：3 个）”
*   **博弈价值**：
    *   玩家只知道“这东西身上还藏着 3 个秘密”，至于这些秘密是让物品价值翻倍的极品特异，还是受力即断的严重暗伤，必须由玩家凭眼力和手艺去验。

## 四、 十大标准工坊检验手法（固定动作池）

所有物品的物理验证，统一收敛在以下 **10 种标准工匠动作**中，杜绝无边际乱猜：

| 编号 | 检验手法名称 | 常用工具/操作方式 | 专门对应的物性与破绽 |
| :--- | :--- | :--- | :--- |
| 1 | **骨锤轻敲** | 紫杉木柄骨锤轻敲边缘 | 内部裂纹、生脆、空洞气泡、金属与硬角暗伤 |
| 2 | **聚光照纹** | 防风聚光灯平视逆光透射 | 晶石双折射、薄卷轴暗痕、药液分层、涂层裂纹 |
| 3 | **微火微温** | 酒精喷灯余烬在不起眼处微烤 | 掺假树脂、蜡封真伪、防腐油脂成分、挥发性气味 |
| 4 | **指肚慢抚** | 闭目以指腹反复滑过器表 | 手工锉痕、修补暗缝、锻打厚薄不均、微小气孔 |
| 5 | **天平沉水** | 浸入带刻度木量筒测排水量 | 原矿掺杂、假金银、异常密度、空心铸件 |
| 6 | **刮粉点水** | 刮取微量碎屑滴入工坊试剂 | 草药受潮霉变、骨材失活、金属锈蚀深度 |
| 7 | **魔力轻注** | 指尖注入微量魔力感受流动 | 符文回路阻滞、法杖导魔性、饰品魔力回流 |
| 8 | **透镜细查** | 双重研磨水晶放大镜观察微观截面 | 齿轮齿牙磨损、寄生虫卵、微小铸造砂眼、防伪刻记 |
| 9 | **柔韧轻别** | 双手握持两端施加微量弯折力 | 干草韧性、皮革硬化、弹簧疲劳、剑身弹性衰退 |
| 10 | **逆毛轻抚** | 顺着纹理抚平后，反向推拂一遍 | 织物防水涂层、羽毛油质留存、木料逆向逆纹 |

## 五、 记事簿的文字找茬与反推逻辑（拒绝模板照抄）

AI 生成物品时，严禁照抄固定模板，必须遵循**工匠因果推导链**：

```
[1. 底层暗伤/特性] ──→ [2. 物理验证手法] ──→ [3. 倒推外在异常表征] ──→ [4. 记事簿生成真假记录]
```

### 1. 记事簿条目的文字找茬机制
玩家消耗 **1 点耐心** 点击【翻阅记事簿】，系统基于当前表征，检索出 2~3 条历史笔记：
*   **正解条目**：表征细节与物品描述 **100% 严丝合缝**，指出正确的检验动作。
*   **干扰陷阱条目**：整体极为相似，但在**关键修饰词上有微妙出入**！
    *   *差异示例*：“反光中水纹顺滑连续游动” vs “水纹在特定位置突兀折断跳跃”；
    *   *差异示例*：“空挥重心平稳下坠” vs “空挥带有细微空腔滞涩颤抖”；
    *   *差异示例*：“散发微酸霉馊气” vs “散发微苦干草腥气”。
*   **误信陷阱的代价**：
    若物品内部有冷隔暗伤，玩家误以为是韧性极佳的风纹钢，采用了【柔韧轻别】——系统判定操作失误，货物在柜台上直接崩裂，品质大幅下滑，顾客耐心额外扣除！

### 2. 真正的经验沉淀
当玩家踩过坑、并在脑海中牢牢记住“水纹跳动折断+空腔沉滞 = 冷隔裂纹 = 必须骨锤轻敲”，下次遇到类似物品，**无需翻书浪费耐心，直接提锤验证**。知识真正留在玩家脑海中。

## 六、 标签等级与免骰看破机制

物品的每个特质标签划分为 **Lv.0 ~ Lv.6**：
*   **Lv.0（完全显性）**：如表面泥垢、手柄油污，进店一眼可知，不产生信息差。
*   **Lv.1 ~ Lv.2（浅层经验）**：熟手掌柜即可看破。
*   **Lv.3 ~ Lv.4（深层行家）**：需工具或特定动作检验。
*   **Lv.5 ~ Lv.6（工坊绝造/罕见特质）**：极致巧合或极为隐蔽的极品/致命隐患。

### 免骰规则：
*   **本能看破**：若 **玩家对应品类专精等级 $\ge$ 标签等级**，进店时该标签**自动直接揭示**，无需消耗耐心与投骰。
*   **跨级检定**：若等级不足，玩家指明了正确手法并执行时，由前端进行掷骰：
    $$\text{检定目标难度 (DC)} = 10 + (\text{标签等级} - \text{玩家等级}) \times 3$$
    $$\text{投骰} = 1\text{d}20 + \text{玩家专精等级} + \text{工坊工具加值} \ge \text{DC}$$
