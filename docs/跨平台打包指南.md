# 《工坊物语》跨平台打包指南 (EXE 桌面版 & APK 安卓版)

本项目为纯原生 HTML5/CSS3/JavaScript 编写的高性能单页 Web 应用，没有任何复杂的编译依赖，天然支持打包为 **Windows 桌面可执行文件 (.exe)** 和 **Android 移动应用安装包 (.apk)**。

---

## 一、 快速生成 Windows 桌面版 (.exe)

项目内置了 **Electron** 配置，可一键将网页包装为独立的 Windows 桌面客户端。

### 1. 准备环境
确保电脑安装了 [Node.js](https://nodejs.org/)。

### 2. 本地安装依赖与运行
在项目根目录下打开终端（Terminal / CMD / PowerShell）：
```bash
# 安装 electron 及打包器
npm install

# 本地以桌面客户端窗口启动预览
npm start
```

### 3. 一键打包为 .exe
```bash
# 执行打包构建
npm run build:win
```
*   打包完成后，可在根目录下生成的 `release/` 文件夹中找到：
    *   `工坊物语 Setup 1.0.0.exe`（安装引导版）
    *   `工坊物语 1.0.0.exe`（绿色便携免安装版，双击直接畅玩）

---

## 二、 快速生成 Android 移动版 (.apk)

项目配置了主流的 **Capacitor** 移动端打包方案，原生无缝封装为安卓 App。

### 1. 准备环境
- 安装 Node.js
- 安装 [Android Studio](https://developer.android.com/studio) 并配置好 Android SDK。

### 2. 初始化 Android 工程
在项目根目录执行：
```bash
# 1. 安装 Capacitor 依赖
npm install

# 2. 生成 Android 原生工程
npx cap add android

# 3. 将网页资源同步至 Android 项目
npx cap sync
```

### 3. 在 Android Studio 中一键编译导出 APK
```bash
# 调起 Android Studio
npx cap open android
```
*   在打开的 Android Studio 窗口中：
    1. 点击顶部菜单栏 `Build` $\rightarrow$ `Build Bundle(s) / APK(s)` $\rightarrow$ `Build APK(s)`；
    2. 等待片刻，右下角弹出通知，点击 `locate`，即可获取编译生成的 `app-debug.apk`！
    3. 直接传输至安卓手机即可安装游玩。

## 三、 免安装环境：极简第三方打包工具推荐

如果您不想在本地配置完整的 Node.js 或 Android Studio 开发环境，也可以使用以下工具快速打包：

1. **PWA2APK / Bubblewrap**：
   - 部署到 GitHub Pages 等静态网页后，直接输入网址生成 APK。
2. **Website 2 APK Builder**：
   - 现成 GUI 工具，选择本项目文件夹（包含 `index.html`），点击 Generate 即可直接生成 APK 文件。
3. **NW.js 或 Web2Exe**：
   - 选择项目根目录，直接导出 Win 64位 .exe。
