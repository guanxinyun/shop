# 《工坊物语》七维炼药与调和系统规范

---

## 一、 系统定位与核心体验

在后院工坊里，炼药不是冰冷的公式计算，也不是简单按一下“合成”按钮，而是**工匠与材料特性的对话**：
*   每种草药、兽材与矿粉都有自己的“脾气”（药性倾向）；
*   把它们丢进坩埚后，药汤会呈现出动态的冷热拉扯与混浊浮沫；
*   掌柜通过**选料搭配、观色闻味、命中对症工序**，将药性驯服在配方允许的区间与标签规范内。

---

## 二、 七维药性属性与对冲轴（百分度刻度模型）

为保证操作手感细腻、提供合理的容错带，并使主料、辅料与微量催化剂能够明确分工，系统采用 **$[-50 \sim +50]$ 的极性对冲刻度** 与 **$0 \sim 100$ 的澄澈度百分制**：

```
    【热性 (Calor)】  ←───── 对冲 ─────→  【冰性 (Frigor)】  [-50 ~ +50]
    【发散 (Volat)】  ←───── 对冲 ─────→  【敛聚 (Fixus)】   [-50 ~ +50]
    【硬化 (Durus)】  ←───── 对冲 ─────→  【柔顺 (Lene)】    [-50 ~ +50]
                            │
                   【澄澈度 (Clarity)】 (0 ~ 100 点)
```

1. **三对对冲轴计算方式**：
   - 素材投入坩埚，数值直接代数相加抵消（单种素材通常提供 $\pm 5 \sim \pm 35$ 点）。
   - **分层配比手感**：
     - **主料（基底）**：提供较大幅度偏移（$\pm 20 \sim \pm 35$）；
     - **辅料（微调）**：用于补足差额、抚平微偏（$\pm 5 \sim \pm 15$）；
     - **催化剂（特异）**：大幅偏向或锁定属性。
   - **剧烈冲撞阈值**：若同一轴上极性差值超过 $40$（例如同时投入热性 $+35$ 与冰性 $+35$），药汤会发生爆沸激荡，直接扣除 25 点澄澈度！
2. **第七维：澄澈度（0 ~ 100 点百分制）**：
   - 决定成药的品质阶位、是否产生副反应、口感与保质期。

### 1. 详细标签定义
*   **感官与形态**：
    1.  `清甜不苦`：小孩、贵族专属；售价 $+30\%$；特定日常托底刚需。
    2.  `刺鼻辛辣`：野葱、生姜生料常带；提神药良性，但在小儿退热或贵族订单中为致命缺陷。
    3.  `挥发异味`：大蒜油、未熟腺体；潜行、驱兽或狩猎订单中绝对禁止。
    4.  `无味无息`：经木炭精滤或特殊萃取；游侠斥候订单刚需。
    5.  `易挂厚膏`：加入蜂蜡或重脂；不易滑落，外用骨膏必备。
    6.  `稀薄易渗`：白井水或薄荷脑浸出；顺滑快速吸收，急救擦剂必备。
*   **药效与机制**：
    7.  `促愈活性`：加速创口结痂收口；高阶外伤药核心标签。
    8.  `麻痹镇痛`：压制剧烈痛楚；重伤急救必备，过量导致肌肉迟钝。
    9.  `清血驱毒`：中和蛇虫酸液与毒素；解毒滴剂必备。
    10. `亢奋强心`：驱除疲劳、加速血流；夜战与行军急需，老人忌服。
    11. `微毒反胃`：生料未净或澄澈度 $\le 3$ 产生；服后恶心干呕，大幅折价。
    12. `舒缓安眠`：平复焦虑、促进深睡；贵族夫人与学者失眠订单指定。
*   **物候与保存**：
    13. `极寒不冻`：严寒大雪天不析出冰晶；冬日巡林与雪山商队溢价 50%。
    14. `易燃爆沸`：含硫磺或烈脂，见火即燃；猛火急煮时会直接炸锅。
    15. `吸湿生霉`：原材受潮未洗；货架存放久了会污染同格其他药材。
    16. `隔水防锈`：涂覆水浇不透；卫队重甲防雨防锈指定。
    17. `快速沉底`：矿粉研磨粗糙；静置易分层，售价打折。
    18. `长久保鲜`：经高阶酒精提取；保质期延长，商会集运溢价 20%。
*   **特异与变质**：
    19. `夜间微光`：暗处散发淡蓝微光；贵族奇趣委托、矿工探穴指定。
    20. `持效延展`：药力持效时间翻倍；公会资深队伍高价抢购。
    21. `极性锁死`：药性被完全锚定，不因外界冷热而挥发或变性。
    22. `药力烈冲`：猛料过量或冰火硬撞；见效极猛但损耗饮用者体力。
    23. `逆向生肌`：调和手法粗暴逆转；愈后留难看凸疤，贵族直接拒收。
    24. `魔力活化`：与法师魔力共鸣；施法前调息专用。

### 2. 标签流转机制：继承、对冲消除与工序洗炼
1.  **材料自然继承**：投入的素材自带标签默认流入药汤（如带泥干叶继承 `吸湿生霉`，生姜继承 `刺鼻辛辣`）。
2.  **极性对冲消除**：
    *   `【刺鼻辛辣】` $\longleftrightarrow$ `【清甜不苦】`（加入蜜果胶可中和辛辣）；
    *   `【挥发异味】` $\longleftrightarrow$ `【无味无息】`（加入活性木炭吸附异味）；
    *   `【微毒反胃】` $\longleftrightarrow$ `【清血驱毒】`（加入净井盐地衣化解微毒）。
3.  **工序洗炼与除标**：
    *   澄澈度拉升至 $\ge 8$ 点（大成功）时，自动洗掉所有负面感官标签，并大概率自发激活 `【清甜不苦】` 或 `【持效延展】`；
    *   使用【亚麻滤网撇沫】直接消除 `【快速沉底】` 与 `【吸湿生霉】`；
    *   使用【微温余烬水浴】平抑躁火，消除 `【易燃爆沸】` 与 `【药力烈冲】`。

## 四、 配方逻辑：目标属性区间 + 必要标签 + 排斥标签

配方设定适度宽松的容错区间（通常跨度为 $15 \sim 25$ 点），避免差 1 点就暴毙的死板挫败感，让掌柜能自由利用主料辅料进行微调：

```json
{
  "recipe_id": "RECIPE_CHILD_FEVER",
  "name": "小儿温和退热糖浆",
  "target_ranges": {
    "calor_heat": [-10, 10],
    "frigor_cold": [20, 35],
    "lene_soft": [15, 30],
    "min_clarity": 55
  },
  "required_tags": [
    "清甜不苦"
  ],
  "forbidden_tags": [
    "刺鼻辛辣",
    "微毒反胃",
    "药力烈冲"
  ]
}
```
*   **达成判定**：
    *   各项属性落在目标区间内；
    *   素材/工序凑齐了所有 `required_tags`；
    *   成功消除或未引入任何 `forbidden_tags`；
    *   三项全部合格，方为【良品】以上。若带有排斥标签，直接降级为【受拒残次品】！

## 五、 开锅初态：随机初始澄澈度（35 ~ 75 点）

素材刚投入坩埚融解时，受当天气温、水质硬度与材料微观干湿度的影响，**澄澈度由系统直接投掷一个 35 ~ 75 点的初始随机值**：

*   **抽到 35 ~ 45 点（浑浊糟糕）**：
    *   *现象描写*：“药水混浊发暗，表面浮起厚厚一层灰黄浮沫，咕嘟咕嘟吐着带有一丝酸糊味的气泡。”
    *   *工匠挑战*：必须立刻采取对症工序进行救场撇沫，否则必定降为残次品甚至报废。
*   **抽到 46 ~ 65 点（寻常合格初态）**：
    *   *现象描写*：“水色呈半透明状，底部隐约沉着细微的药草碎渣，药香温和但略带杂味。”
*   **抽到 66 ~ 75 点（极佳初相）**：
    *   *现象描写*：“药汤泛着温润漂亮的微光，几乎看不见散乱浮渣，空气中弥漫着纯正的草木清香。”

### 4. 配方获取时的“分支残缺”与掌柜手记自补全

*   **平民大婶传授的旧方**：默认只附带【分支 A：市井温和派】的连招；
*   **守备队发下的军用军需单**：默认只附带【分支 B：行伍狂暴派】的连招；
*   **古代卷轴残篇**：三大分支可能全部全盲，标注为 `[分支 A: ? > ? > ?]`、`[分支 B: ? > ? > ?]`、`[分支 C: ? > ? > ?]`。

#### 掌柜的经验沉淀（三大分支独立解锁与记录）：
*   当玩家手握一张配方，尝试用不同的 3 连招烹调时，一旦打出尚未被收录的另一个分支，系统立刻高亮触发：
    > *“你在配方手札上翻开新的一页，用炭铅笔写下全新心得：‘若改用强沸两次促其挥发，此药竟能爆发出惊人的止血狂暴之性！’*  
    > **（该配方【分支 B：行伍狂暴派】连招已永久收录！）**”
*   今后在后院工坊制作时，配方栏直接提供 **3 个流派标签切换**，点击任意已解锁分支即可**一键依手札施术**，为不同客人针对性定制！

## 七、 品阶判定与结算

配方设定**允许波动的目标区间**与**标签白黑名单**：

### 四档品质出炉标准（百分制）：
1. **完美无瑕（Masterwork）**：
   - 目标属性全部落在目标区间内，满足所有必带标签且无排斥标签，最终澄澈度 $\ge 80$ 点。
   - *奖励*：瓶身透亮微光，市价 $+50\%$，并额外激发良性词缀（如：`【清甜不苦】`、`【温润留香】`），深受镇上贵族或小朋友喜爱。
2. **良品（Standard）**：
   - 属性落在区间内，满足必带标签且无排斥标签，最终澄澈度 $\ge 50$ 点。
   - *结果*：标准成药，按基准市价全额出货或交付委托。
3. **偏枯残次品（Flawed）**：
   - 某一项属性微量越界，或带有轻微负面感官标签，或澄澈度处于 $25 \sim 49$ 点。
   - *结果*：药名变更为“微苦发浑的退热水”，售价折半，只能降价卖给不挑剔的过路苦工。
4. **炸锅报废（Burnt Slag）**：
   - 对冲差值超过 40 且误用相冲工序，或澄澈度跌破 $25$ 点。
   - *结果*：锅底焦糊，只剩一团刺鼻的黑炭渣，消耗原料且一无所获。

## 八、 特殊素材作为“炼金催化剂”

高等级（Lv.5 ~ Lv.6）或带有罕见特异的原料，可直接投入坩埚充当**催化剂**，触发以下特异质变：
*   **绝对稳定垫（Stabilizer）**：直接抹平任何冰火冲突，初始澄澈度强行锁定为最大值 100 点。
*   **附加专属特异Tag（Mutation）**：赋予药水`【完全无味】`（巡林潜行专用）、`【夜光显影】`或`【持效翻倍】`等稀有词缀，专供高赏金支线委托。
*   **阶位强行跃迁（Tier Leap）**：使原本寻常的药剂升华为闪耀白银光泽的“名品”。
