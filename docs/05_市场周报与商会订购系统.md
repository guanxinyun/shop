# 《工坊物语》市场周报与商会订购系统规范

## 一、 每周市场行情周报（Market Trend Forecast）

杂货铺经商的核心心跳在于**打信息差与提前囤货**。
每周一清晨，邮差会把一张《小镇商会快讯与周报》塞进店门投信口：

```

│ · 近郊哥布林营地活跃：【轻型兵刃与箭矢】收购价 +25%         │
│ · 镇南石桥修缮完毕：【日用瓷器与杂货】运输顺畅，售价 -10%  │
```

### 玩家的经营心流闭环：
1. **本周操作（布局）**：
   - 获知下周“草药与药水暴涨 40%”，本周有采药人进店时尽力压价收货，并动用流动资金向商会订购囤料；
   - 获知下周“金属原矿暴跌 30%”，趁着本周未降价，将积压的生铁迅速清空。
2. **下周兑现（收获）**：
   - 采购官进驻，原价 5 银币的成药以 7~8 银币大批量出货，享受商业预判带来的扎实收益。

## 二、 供应链：125% 基准价订购系统（Wholesale Catalog）

为彻底解决“想炼药却碰不到客人来卖原料”的断档痛点，商会提供**同行拆借与常备订购网络**。

### 1. 订购规则
*   **解锁条件**：必须是玩家在游戏中**成功鉴定或入库过一次**的原料/辅料（录入个人图鉴）。
*   **订购价格**：固定为**物品基准市场价的 125%**（包含商会代采费与加急运费）。
*   **到货时间**：每日上午下单，次日清晨由邮差直接送达后院仓库。
*   **每日配额**：受店铺商誉等级限制（防止无限订购破坏经营节奏）。

### 2. 经济学逻辑：为什么是 125%？
*   **杜绝无脑倒卖套利**：按 125% 买进再原样转卖，除去税费必亏，玩家无法靠倒买倒卖商会货物刷钱。
*   **激励工坊深加工**：
    *   花 8 银币在柜台向冒险者收购草药，订购需要 **10 银币**；
    *   但经过后院坩埚加工成药水，成品售价可达 **20 ~ 30 银币**；
    *   多出的 2 银币成本完全被炼金的高附加值覆盖，保证掌柜每天开炉生产的稳定性。
